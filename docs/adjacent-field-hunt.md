**Purpose:** Ranked inventory of global signals adjacent to Mixture of Limits (MoL) — mathematical compression vs scaling LLMs for science; formula-first / closed-form / physics-executable cascades; agents that build or drive physical instruments.

## Class legend

| Class | Meaning |
|---|---|
| **true physics-executable cascade** | Closed-form / symbolic / DFT / MD / Lean verification / robotic synthesis that *executes* physics or formal proof, not just narrates it |
| **hybrid LLM+physics** | LLM agents orchestrate simulators, SR, DFT, labs; model is residual orchestrator |
| **mechanistic / compression-first** | Explicit claim: mechanisms, parsimony, MDL, reusable laws > predictive scale |
| **pure scale** | Predictive GNNs / foundation models / agent paper mills; physics as training prior or post-hoc DFT filter |

**MoL lens:** floors where more bits stop buying outcomes; cascade `Lookup → Formula → Solver → Model LAST`; MoL ≠ MoE (limits outside generation, not experts inside).

### Tier A — Formula / mechanism / executable physics (hunt hard)

**1. AI Feynman (+ 2.0) — Udrescu & Tegmark**  
- **Who:** Silviu-Marian Udrescu, Max Tegmark (MIT)  
- **What:** Physics-inspired symbolic regression; NN finds symmetries/separability then recursively recovers closed-form laws (100/100 Feynman eqs; 90% hard bonus set). 2.0 adds Pareto complexity + graph modularity.  
- **URL:** https://www.science.org/doi/10.1126/sciadv.aay2631 · https://papers.neurips.cc/paper/2020/hash/33a854e247155d590883b93bca53848a-Abstract.html  
- **Class:** true physics-executable cascade  
- **Why MoL:** Canonical *Formula* gear — compress mystery data to equations; NN is tool for decomposition, not substrate. Direct MathGround twin.

**2. SINDy — Brunton / Proctor / Kutz**  
- **Who:** Steven L. Brunton, Joshua L. Proctor, J. Nathan Kutz  
- **What:** Sparse identification of nonlinear dynamics — library of candidate terms + sparse regression → parsimonious ODEs from data.  
- **URL:** https://www.pnas.org/doi/10.1073/pnas.1517384113  
- **Class:** true physics-executable cascade  
- **Why MoL:** Explicit *grammar* + sparsity floor; rejects dense residual fits. AutoSINDy (2026) hybrids PySR discovery → curated library → SINDy solve ([arXiv:2605.09696](https://arxiv.org/html/2605.09696v1)).

## One-line MoL takeaway

The live frontier splits cleanly: **(A)** formula/mechanism discovery that compresses data into reusable laws (Feynman/SINDy/PySR/AI-Newton/MWMs), **(B)** hybrid agents that keep DFT/MD/robots as the executable floor (Buehler AtomAgents, MACE harnesses, A-Lab), and **(C)** scale workflows that automate papers/hypotheses without a mechanistic substrate (Sakana, much of Co-Scientist, Cosmos-as-science branding). MoL’s wager is that **A’s floors + B’s physics leaves** beat **C’s token escalation** — and that MoE-style mixtures are the wrong “Mixture of.”
