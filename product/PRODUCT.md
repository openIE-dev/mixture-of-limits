**Author:** David Charlot / OpenIE  
**Status:** Product embodiment package (declarative chore + acceptance + architecture). Soft-ref constructive existence already ships in the Rust clean-room (`mol prove`). This package turns the law into an operator-facing product surface — not another diagnosis paper.

## Problem

After grammar, VoI, and energy floors, industry stacks still burn unbounded tokens. Completeness `C(z)` is never written, so loops never stop. Estimates get labeled as board joules. Model-generated proposals commit without a Notational Intelligence (NI) certificate. The global problem is the same class Laya answers for typed option sets — except most chores are not closed option sets: they need **navigation + certify-before-commit + satiation stop** for any written `C(z)`.

## Value proposition vs Laya

| | **Laya (System One)** | **Mixture of Limits product** |
|---|---|---|
| Problem class | Typed decisions over **known option sets** | Any chore with a written completeness predicate `C(z)` |
| What it owns | Fast, typed System One proposals in software | Navigation floors → NI certify → commit\|refuse → satiation stop |
| What it does not own | Plant motion; economic done | Replacing System One for closed menus |
| Complement | Proposer when the option set is typed | WCA/NI commit gate + Mixture of Limits cascade + `C(z)=1` refuse |

Laya collapses generation cost when the option set is known ([laya-ai.com/system-one-models](https://laya-ai.com/system-one-models)). Mixture of Limits product answers the complementary global problem: **stop unbounded spend after floors**, certify irreversible acts, and halt when `C(z)=1` — including chores where the option set is open until grammar/VoI say otherwise.

Cited already in OpenIE research triad (NI + Satiation papers): System One = typed proposers (Laya / Jev class); WCA decides whether the machine may move.

**Competitive note (2026):** Mixture of Limits competes head-on. On Arena-shaped chores (typed decision / ticket-close / risk), `mol arena` scores MoL cascade vs frontier always-model vs System One leaf (Jev/Laya-class stub) on **correct_close**, **refuse-when-C=1**, **estimated_j**, and latency. Floors win when they exist; Model LAST still opens when needed; peers age; each stands alone; frontier is expensive/out of road; time is fair. TypeSafe **Jev** and open System One peers remain lawful residual proposers — and still lose close-law rows when they ignore VoI / satiation. ## Value prop (one sentence)

**Mixture of Limits product** is the operator surface that runs Lookup → Formula → Solver → Model LAST under named floors, commits only with an NI certificate, stamps honest joule receipts (`estimated_j` always; `measured_j` only when a meter is present), and refuses further synthesis when `C(z)=1`.

## MVP scope

1. Declarative chore (`mol.yaml`) with limits, cascade pipeline, `on_refuse`, and written `C(z)`.
2. Soft-ref close path wired to existing Rust clean-room: `mol prove` (exists) + `mol run --chore <yaml>` (stub → load yaml → close).
3. Acceptance tests in ACCEPTANCE.md: O(1) grammar hit → no model; VoI=0 → refuse; `C=1` → satiation stop; `ModelGenerated` never commits without NI cert; estimate joules on every receipt; `measured_j` only when meter present.
4. One concrete chore: support-desk ticket close (primary). Optional sketch: `financial_risk_scoring` (secondary YAML).
5. Architecture doc for dual-phase micro-perception → Mixture of Limits stack → NI commit → satiation; Primitive Distillation Loop **v1 hardened** (second pass Lookup/Formula without model).

- Not inventing Arena/JevBench composite scores as MoL scores; System One remains Model LAST for closed menus after floors miss — and still faces `mol arena` close-law scoring.
- Live WCA **MCP network** / Ferric robot EFA / klere-vm FPGA Stage C package meters remain out of soft-ref prove (in-crate NI certify + Stage C unmetered **are** in prove).
- Remaining ~78/258 Periodic Stack thesis primitives still residual (live catalog ≥170 gears in prove; counts honest in scale_note).
- Not a new consumer brand name without explicit approval (see name table).

## Physics-informed voice (lock)

- Say **Mixture of Limits** in full on first use.
- Floors are physics- and information-theoretic: VoI, grammar, Landauer/catalog energy as **estimate**, certificate, settle-refuse.
- **Estimates ≠ `measured_j`.** Receipts always carry labeled `estimated_j`. Package `measured_j` appears only under a Metered probe.
- No honesty hedges that weaken the refuse law. Refuse is success when VoI=0 or `C(z)=1`.
